## Audit framework
The report applies the Session 6 reproducibility scorecard: repeated runs/seeds, experimental partitions, leakage/contamination, tuning separation, statistical rigor, effect size and confidence intervals, external validation, compute documentation, and code/data availability.

## Important scope note
The audited study is a single-case experimental AAC study using a Wizard-of-Oz context-aware prototype rather than a trained stochastic ML model. Accordingly, ML-specific criteria are interpreted by their underlying reproducibility principle and this limitation is stated explicitly in the report.
