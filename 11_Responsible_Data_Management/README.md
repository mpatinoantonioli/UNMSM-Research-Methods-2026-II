Scope and scientific integrity
The doctoral project proposes a Spanish-language, human-in-the-loop multimodal Augmentative and Alternative Communication (AAC) prototype designed to support functional communication in autistic children requiring very substantial support.

Current research stage: This is a prospective DMP. No participant data have been collected. Outstanding ethics approvals, data-processing arrangements, infrastructure settings, and security controls are not represented as completed.

Privacy boundary: This repository contains no children's names, identifiable photographs, recordings, health records, or interaction logs. Only authorized public documentation, source code, metadata, synthetic examples, and sufficiently aggregated research outputs may be considered for release.
